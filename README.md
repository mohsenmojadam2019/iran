# Buffy

اسکریپت‌ها و تنظیمات عمومیِ قابل‌انتقال برای Buffy، دستیار محلی سیستم.

## نصب

```bash
./install.sh
```

این بسته فقط کد و فایل‌های عمومی را نصب می‌کند. توکن‌ها، کلیدهای SSH، پروفایل مرورگر، پایگاه‌داده، تاریخچه و لاگ‌ها باید جداگانه روی هر سیستم تنظیم شوند.

## نیازمندی‌ها

- Python 3
- ابزارهای موردنیاز هر اسکریپت، مانند `git`، `gh`، `ssh` و در صورت نیاز `docker`
- تنظیم دستی متغیرهای محیطی و سرویس‌های محلی
